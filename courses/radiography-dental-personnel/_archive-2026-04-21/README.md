# Archive — Legacy design artifacts (April 2026)

This folder contains the original Radiography for Dental Personnel design artifacts produced during the April 2026 design phase. **These files describe a course that was never built.**

The original design called for a **64-hour hybrid course** (56 online + 8 in-person clinical day) across **13 content modules (M0–M12)** with an **80% passing threshold**, **30/30/40 weighted gradebook**, **100-item proctored final exam**, and a **7-competency clinical rubric**. None of that survived the 2026-05-02 restructure.

**The current, live, authoritative course is a 14-hour 6-week design.** See the parent folder `README.md` and `ARCHITECTURE_SNAPSHOT_2026-05-02.md` for current state. See `../CHANGELOG.md` for the full narrative of what changed and why.

These files are preserved here for **design-history archeology** — to understand the design journey, the original blueprint and gap analyses, and the legacy clinical rubric (which informed but did not become the current Capstone rubric). **Do not use these files as authoritative reference.** If anything in this folder contradicts current state, current state wins.
